# Authority playbook (white-hat only)

Load `nxt-seo-rules`. Never: buying links, PBNs, fake reviews, fake offices or GBP listings, link exchanges at scale, doorway pages, cloaking, keyword stuffing, AI spam. These risk a manual action that erases all other work.

## 1. Link magnets we can build (highest leverage)
| Asset | Why it earns links | Build notes |
|---|---|---|
| **Original data report** (e.g. "Home tuition fees across Indian cities, 2026"; "What parents search in the board year") | Journalists and parenting blogs cite original numbers | From our own anonymised requests/search events only; method section; publish as a pillar post with a chart; pitch to education desks |
| **Free tools**: fee calculator (monthly cost from hourly rate), CBSE/ICSE percentage calculator, IB points calculator, board-exam countdown, study-timetable generator | Schools and blogs link to useful tools | One page per tool, fast, no login; embed code for schools |
| **Resource library**: worksheets, markschemes, PYQ solutions (Ajay's IB material with permission) | Teachers link to free, expert resources | PDF + HTML summary page per resource; author credit; no copyrighted board papers without permission |
| **Tutor-authored guides** | Real names + expertise; scales with supply | Reviewed via `nxt-content-audit`; author profile page each |

## 2. Local and brand signals
- **Google Business Profile** (Sector 66, "Nxtutors Edtech - Home Tutors", kgmid `/g/11z1lm_3_m`, linked in schema `sameAs`): real name only (no keyword stuffing), category Tutoring service, service areas, services, weekly posts linking new guides, photos, **review requests to real parents after a good demo/month**. One profile per real location only.
- **Consistent listings (NAP)**: Justdial, Sulekha, UrbanPro, Google — same name, address, phone (+91 78360 34313), website.
- **Offline → online**: free board-exam or IB workshops in societies, RWAs, school PTAs → newsletter/website mentions and reviews.
- **Community answers**: Reddit r/gurgaon, Quora — genuinely helpful answers linking a guide only when it answers the question.

## 3. Digital PR routine (monthly)
Reply to journalist requests (Qwoted, Help a B2B Writer, Featured) on education/parenting with Ajay as the expert; pitch each data report to 10–20 relevant journalists; keep a simple tracker (outlet, contact, date, result).

## 4. AI-search visibility
Pages cited by AI answers share: answer-first intros, clear entities, dated facts, tables, named expert authors, and presence on sites AI engines read (listings, forums, news). Apply `nxt-content-audit` CITE; track a fixed list of 20 prompts ("best IB maths tutor Gurgaon", "home tuition fees Gurgaon"…) monthly by asking the AI engines manually and noting whether NXTutors is mentioned.

## 5. Measure
Referring domains and branded searches (GSC queries containing "nxtutors"), GBP views/calls, review count and rating, tool/resource page traffic — reviewed in `nxt-gsc-review`.
